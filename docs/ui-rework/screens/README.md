# Flimmer – Screens (Richtung „Mischung“)

Vorlage für die Code-Agenten „ui-fundament“ und „ui-player“. Jede Datei ist statisches HTML in fester Größe: TV 1920 × 1080, Desktop 1440 × 900, Handy 390 × 844.

- Die Stile kommen aus `flimmer.css`. Die Datei wird aus `tokens.json` und `bundle.css` des Designsystems erzeugt, die Klassennamen entsprechen den Komponenten dort.
- Die Schriften liegen lokal unter `schriften/`:
  - Flimmer Plakat: Archivo, Breite 62, Gewicht 800, als statische Instanz
  - IBM Plex Sans
  - IBM Plex Mono
- Die Standbilder unter `bilder/` sind gezeichnete Platzhalter.
- Positioniert wird für die feste Bildschirmgröße absolut. Im Code gelten die Flexbox-Regeln aus dem Designsystem.
